# 作业文件整理工具 (Homework Organizer)

一个命令行小工具，帮助学生批量整理作业文件：扫描列出、按规则重命名、按类别归档，并支持撤销。

纯 Python 标准库实现，无需额外依赖。

## 功能

| 子命令 | 说明 |
|--------|------|
| `list` | 扫描文件夹，列出所有文件的大小和修改时间，支持按扩展名过滤 |
| `rename` | 按规则批量改名，操作前预览并需用户确认，自动处理重名冲突 |
| `archive` | 按扩展名或文件名字段（如学期）归档到子文件夹，生成整理报告 |
| `undo` | 撤销上次归档操作，文件归位并清理空文件夹 |

## 安装

```bash
git clone <仓库地址>
cd homework-organizer
# 仅使用 Python 3.10+ 标准库，无需 pip install
```

## 使用说明

### 1. 扫描与列出

```bash
python -m homework_organizer list <文件夹> [--ext .pdf,.docx]
```

- 列出文件夹中所有文件的名称、大小、修改时间
- `--ext` 仅显示指定扩展名的文件，多个用逗号分隔

示例：

```
$ python -m homework_organizer list ./作业 --ext .pdf
文件名                                  大小      修改时间
------------------------------------------------------------------------
2023001_张三_数学作业.pdf            21.0 B  2026-10-08 22:07:23
2023003_王五_英语作业.pdf            16.0 B  2026-10-08 22:07:23
------------------------------------------------------------------------
共 2 个文件
```

### 2. 批量改名

```bash
python -m homework_organizer rename <文件夹> --pattern "{id}_{name}_{title}" --output "{title}_{id}" [--ext .pdf] [--delimiter "_"]
```

- `--pattern`：输入文件名的解析模式，用 `{字段名}` 占位
- `--output`：输出文件名模板，使用相同的字段名重组
- 最后一个字段贪婪匹配，允许包含分隔符
- 改名前会打印完整计划，必须输入 `y` 确认后才会执行
- 目标文件已存在时自动跳过，**绝不覆盖**

示例：`2023001_张三_数学作业.pdf` → `数学作业_2023001.pdf`

```
$ python -m homework_organizer rename ./作业 --pattern "{id}_{name}_{title}" --output "{title}_{id}"
============================================================
重命名计划预览（尚未执行）
============================================================
  2023001_张三_数学作业.pdf
    → 数学作业_2023001.pdf
============================================================
将重命名 1 个文件，跳过 0 个。
确认执行以上重命名？(y/N): y
  ✓ 2023001_张三_数学作业.pdf → 数学作业_2023001.pdf
```

### 3. 归档与报告

按扩展名归档（默认）：

```bash
python -m homework_organizer archive <文件夹> [--by ext] [--ext .pdf,.docx]
```

按文件名字段归档（如学期）：

```bash
python -m homework_organizer archive <文件夹> --by name --pattern "{semester}_{id}_{name}_{title}" --field semester
```

- `--by ext`：按扩展名分类（PDF / Word / Excel / Images 等）
- `--by name`：从文件名提取指定字段作为类别（如学期 `2024秋`、`2025春`）
- 归档前打印计划并需确认
- 自动生成整理报告，打印到控制台并保存为 `整理报告_<时间戳>.txt`
- 报告包含：成功归档数、跳过数及原因、失败数及原因

### 4. 撤销上次操作

```bash
python -m homework_organizer undo <文件夹>
```

- 读取上次归档的操作记录，将文件移回原位置
- 自动清理空的类别子文件夹
- 仅撤销最近一次操作；若原始位置已有文件则跳过

## 安全设计

- **改名/归档前必须确认**：所有会修改文件的操作都会先打印计划，用户输入 `y` 才执行
- **绝不覆盖已有文件**：遇到重名冲突自动跳过并报告原因
- **可撤销**：归档操作记录在 `.organizer_history.json`，可随时撤销
- **二次检查**：执行前再次校验源/目标状态，防止预览后状态变化导致错误
